#  商品管理システム テーブル定義書

## 1. テーブル一覧

| テーブル物理名 | テーブル論理名 | 説明 |
| :--- | :--- | :--- |
| categories | カテゴリマスタ | 商品カテゴリの階層構造を管理するマスタテーブル |
| products | 商品マスタ | 商品の基本情報・価格を管理するマスタテーブル |
| stocks | 在庫 | 商品ごとの在庫数・発注点を管理する |
| product_images | 商品画像 | 商品に紐づく画像URLと表示順を管理する |

---

## 2. 各テーブルのカラム定義

### (1) categories

| # | カラム名 | 論理名 | データ型 | NOT NULL | PK | FK | デフォルト値 | コメント |
| :-: | :--- | :--- | :--- | :---: | :---: | :---: | :--- | :--- |
| 1 | category_id | カテゴリID | VARCHAR(50) | ○ | ○ | - | - | 例：CAT-01 |
| 2 | category_name | カテゴリ名 | VARCHAR(255) | ○ | - | - | - | 例：家電、書籍 |
| 3 | parent_category_id | 親カテゴリID | VARCHAR(50) | - | - | ○ | NULL | categories.category_idを自己参照（null=ルート） |
| 4 | description | カテゴリ説明 | TEXT | - | - | - | NULL | カテゴリ説明 |
| 5 | display_order | 表示順 | INT | ○ | - | - | 0 | 表示順 |
| 6 | is_active | 有効フラグ | TINYINT(1) | ○ | - | - | 1 | 1=true, 0=false |
| 7 | created_at | 登録日時 | DATETIME | ○ | - | - | NOW() | 登録日時 |
| 8 | updated_at | 更新日時 | DATETIME | ○ | - | - | NOW() | 更新日時 |

---

###  (2) products

| # | カラム名 | 論理名 | データ型 | NOT NULL | PK | FK | デフォルト値 | コメント |
| :-: | :--- | :--- | :--- | :---: | :---: | :---: | :--- | :--- |
| 1 | product_id | 商品ID | VARCHAR(50) | ○ | ○ | - | - | 例：PROD-0001 |
| 2 | product_name | 商品名 | VARCHAR(255) | ○ | - | - | - | 商品名 |
| 3 | category_id | カテゴリID | VARCHAR(50) | ○ | - | ○ | - | categories.category_idへの外部キー |
| 4 | sku | SKUコード | VARCHAR(50) | ○ | - | - | - | 例：SKU-ABC-001 |
| 5 | unit_price | 販売単価（税抜） | INT | ○ | - | - | 0 | 販売単価（税抜） |
| 6 | cost_price | 仕入れ単価 | INT | ○ | - | - | 0 | 仕入れ単価 |
| 7 | description | 商品説明 | TEXT | - | - | - | NULL | 商品説明 |
| 8 | is_active | 販売中フラグ | TINYINT(1) | ○ | - | - | 1 | 1=true, 0=false |
| 9 | created_at | 登録日時 | DATETIME | ○ | - | - | NOW() | 登録日時 |
| 10 | updated_at | 更新日時 | DATETIME | ○ | - | - | NOW() | 更新日時 |

---

###  (3) stocks

| # | カラム名 | 論理名 | データ型 | NOT NULL | PK | FK | デフォルト値 | コメント |
| :-: | :--- | :--- | :--- | :---: | :---: | :---: | :--- | :--- |
| 1 | stock_id | 在庫ID | INT | ○ | ○ | - | - | 自動採番（PK） |
| 2 | product_id | 商品ID | VARCHAR(50) | ○ | - | ○ | - | products.product_idへの外部キー（1対1） |
| 3 | quantity | 現在在庫数 | INT | ○ | - | - | 0 | 現在在庫数 |
| 4 | reorder_point | 発注点 | INT | ○ | - | - | 10 | この数を下回ったら発注 |
| 5 | reorder_quantity | 発注数量 | INT | ○ | - | - | 0 | 発注数量 |
| 6 | warehouse_location | 倉庫内保管場所 | VARCHAR(255) | - | - | - | NULL | 例：A-3-2 |
| 7 | created_at | レコード作成日時 | DATETIME | ○ | - | - | NOW() | レコード作成日時 |
| 8 | updated_at | 在庫更新日時 | DATETIME | ○ | - | - | NOW() | 在庫更新日時 |

---

### (4) product_images

| # | カラム名 | 論理名 | データ型 | NOT NULL | PK | FK | デフォルト値 | コメント |
| :-: | :--- | :--- | :--- | :---: | :---: | :---: | :--- | :--- |
| 1 | image_id | 画像ID | INT | ○ | ○ | - | - | 自動採番（PK） |
| 2 | product_id | 商品ID | VARCHAR(50) | ○ | - | ○ | - | products.product_idへの外部キー |
| 3 | image_url | 画像URL | VARCHAR(255) | ○ | - | - | - | 画像のURL |
| 4 | alt_text | 代替テキスト | VARCHAR(255) | - | - | - | NULL | 代替テキスト |
| 5 | is_primary | メイン画像フラグ | TINYINT(1) | ○ | - | - | 0 | 1=true, 0=false |
| 6 | sort_order | 表示順 | INT | ○ | - | - | 0 | 表示順 |
| 7 | created_at | 登録日時 | DATETIME | ○ | - | - | NOW() | 登録日時 |
| 8 | updated_at | 更新日時 | DATETIME | ○ | - | - | NOW() | 更新日時 |
