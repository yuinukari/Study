# タスク管理システム 処理詳細設計書

## 1. メソッド処理詳細

### 1. MemberRepository.findById
* **メソッド名：** `MemberRepository.findById(String memberId)`
* **処理概要：** 登録されているメンバーの中から、引数で指定されたメンバーIDを持つメンバーを検索して返却します。
* **引数：**
  * `memberId` (String) : 検索対象のメンバーID
* **戻り値：**
  * `Member` : 一致したメンバーオブジェクト（見つからない場合は null）

#### 処理ステップ
1. ループ変数 `i` を 0 から `count - 1` まで 1 ずつ増やしながら以下の処理を繰り返す（配列 `members` の走査）。
2. if：`members[i].getMemberId()` が 引数 `memberId` と一致するか判定する。
   - 一致する場合（true）：該当するメンバーオブジェクト `members[i]` を戻り値として返却し、メソッドを終了する。
   - 一致しない場合（false）：次の要素のループ処理へ進む。
3. 全件走査（ループ終了）しても一致するメンバーが見つからなかった場合、elseとして `null` を返却する。

#### 例外・特記事項
* 引数に指定されたメンバーIDが存在しない場合は `null` を返却するため、呼び出し側でのヌルチェックを推奨します。

### 2. TaskService.addTask
* **メソッド名：** `TaskService.addTask(Task task)`
* **処理概要：** 引数で渡されたタスクをシステム内の配列に登録し、登録の成否を判定します。
* **引数：**
  * `task` (Task) : 登録対象のタスクオブジェクト
* **戻り値：**
  * `boolean` : 登録成功時は true、配列の上限に達しており登録失敗時は false

#### 処理ステップ
1. if：現在のタスク登録件数 `taskCount` が タスク配列の上限数 `tasks.length` 未満であるか判定する（配列に空きがあるかのチェック）。
   - 条件を満たす場合（true）：
     1. タスク配列 `tasks` の `taskCount` 番目の位置に引数の `task` を格納する。
     2. `taskCount` の値を 1 加算（インクリメント）する。
     3. 登録成功を意味する `true` を返却して終了する。
   - 条件を満たさない場合（false）：
     1. 配列の上限に達しているため、登録失敗を意味する `false` を返却して終了する。

#### 例外・特記事項
* 配列の最大容量（`tasks.length`）を超えてタスクを追加しようとした場合、例外はスローせず `false` を返却して安全に終了する仕様となっています。

### 3. TaskService.printTaskList
* **メソッド名：** `TaskService.printTaskList()`
* **処理概要：** 登録されているすべてのタスクの一覧を担当者（メンバー）名と役割を含めて標準出力（コンソール）に表示します。
* **引数：** なし
* **戻り値：** `void`（なし）

#### 処理ステップ
1. コンソールにヘッダー文字列 `"===== タスク一覧 ====="` を出力する。
2. ループ変数 `i` を 0 から `taskCount - 1` まで 1 ずつ増やしながら以下の処理を繰り返す。
3. 配列から現在のタスクオブジェクト `Task task = tasks[i]` を取得する。
4. `memberRepository.findById(task.getAssigneeId())` を呼び出し、タスクの担当者IDに紐づくメンバー情報を検索して `Member member` に格納する。
5. if：取得した `member` が `null` ではないか判定する（担当者の存在チェック）。
   - 存在する（true）：`task.toDisplayString()`、`member.getMemberName()`、`member.getRole()` の情報を指定のフォーマット（左寄せの30桁・8桁等）に成形し、コンソールに一行出力する。
   - 存在しない（false）：出力処理を行わず、次の要素のループ処理へ進む。

#### 例外・特記事項
* タスクに設定されている担当者ID（`assigneeId`）が `MemberRepository` に登録されていない場合（`null` の場合）、そのタスクは画面に表示されずスキップされます。
